# Лабораторные по вычислительным алгоритмам 2026 (сданы В.М.Градову)
### Общие замечания
Если для решения нужны какие-то математические преобразования сложнее a + b = c; b = c - а, то пишите их в тетрадку, тетрадку берите с собой на защиту. Показывайте ее Градову - так все будет сильно проще. Иначе все это придется расписывать при нем без единой ошибки. Объяснения/обоснования берите либо из его лекций, либо из литературы, которую он советуют - нейронка может не прокатить. <br>
Надо действительно разбираться в том, что приносите, правильная программа это ну может 25% сдачи. В среднем в начале пары спрашивает больше и жестче, чем в конце. Делает выводы о том, какую оценку надо поставить на Л/Р N на основе оценок за Л/Р 1...N-1, так что репутацию надо зарабатывать сразу. <br>
### Замечания по конкретным лабам (что вспомнил)
1. Во-первых, я это надипсичил - поэтому код красивый и вывод хорошо оформлен. 2. Написано руками. Ключевые вопросы (но бывают и разные другие): что будет, если C1=C2; почему сплайн на концах плохо интерполирует; как это исправить; откуда берутся все нужные уравнения для получения коэффициентов кубического сплайна
3. Часть руками, часть с привличением студента Дипсикова. Градов у всех смотрит, можно ли получить полином N-ой степени по N точкам. По математике - этого сделать нельзя, но обычно у всех получается, потому что Гаусс хавает вырожденную систему и выдает на определителе элементы порядка 1е-10. Надо это через эпсилу заифать. У меня в этой части вообще что-то странное, ошибки такой не возникает, полином строится... в общем сдал как-то, по сути работает не совсем правильно.

Якобиан обязательно распишите заранее в тетрадке - вы же не брали эти 4 производные в уме, правда?

Надо четко понимать алгоритм двумерного интегрирования (лучше всего заранее написать в тетрадку).
